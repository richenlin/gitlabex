作业内容

本次作业我完成了轨道参数计算的全部要求，包括：

  1. 计算了LEO卫星的轨道参数
  2. 分析了轨道稳定性
  3. 评估了轨道衰减率
  4. 提出了轨道优化建议

以下是我的计算结果和分析报告：

# 轨道参数计算 a = 7000 km # 半长轴 e = 0.001 # 偏心率 i = 51.6° # 倾角 Ω = 120° # 升交点赤经 ω = 90° # 近地点幅角 M = 0° # 平近点角
