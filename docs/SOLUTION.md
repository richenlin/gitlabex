# GitLabEx 教育协作平台 - 需求规格说明书 (V2.0)

## 1. 项目概述

### 1.1 项目背景
GitLabEx 是一个基于 GitLab 生态系统的教育协作平台，专为教学场景设计。平台深度集成 GitLab 的核心能力，为教育机构提供完整的在线教学、课题研究和协作开发解决方案。

### 1.2 设计理念
- **最大化复用 GitLab 能力**：直接利用 GitLab 的用户管理、权限控制、项目管理等成熟功能
- **教育场景优化**：针对教学流程和师生角色特点进行专业化设计
- **简化操作流程**：提供直观易用的界面，降低技术门槛
- **企业级安全**：基于 OAuth 2.0 认证和完整的 API 安全机制
- **扩展性强**：支持第三方系统集成和功能扩展

### 2.2 技术栈
**前端技术栈**：
- Vue 3.4+ with TypeScript
- Element Plus UI 组件库
- Vite 构建工具
- Pinia 状态管理
- Vue Router 路由管理

**后端技术栈**：
- Go 1.21+ with Gin 框架
- PostgreSQL 15+ 数据库
- Redis 7+ 缓存
- JWT 身份认证

**集成服务**：
- GitLab CE 版本控制
- MinIO 对象存储
- Docker 容器化部署

## 3. 功能需求

### 3.1 用户管理
- 用户信息完全从 GitLab API 实时获取
- 支持四种角色：管理员(Owner)、教师(Maintainer)、研究员或学生(Developer)、普通用户（Reporter）、游客（Guest）
- 用户可管理个人资料、SSH 密钥、GPG 密钥和账户设置
- 管理员拥有完整的用户管理权限

### 3.2 角色功能
- **管理员角色**：管理员拥有完整的用户管理权限以及所有功能权限
- **系统角色管理**：管理员可管理用户角色，新增用户默认角色为普通用户
- **教师角色**：教师可以管理课题、话题、文档
- **研究员**：可以参与课题，新增、编辑、删除自己的话题，管理、下载文档
- **学生**：可以参与课题，新增、编辑、删除自己的话题，管理、下载文档，还可以提交作业
- **普通用户**：可以查看课题、话题，查看、下载文档
- **游客**：可以访问网站首页（课题列表、热门话题、活动列表）、话题（话题列表）、话题栏目（文档列表）

### 3.3 课题管理
- **课题类型**：分为公开课题和专有课题
- **创建权限**：管理员和教师可创建课题（自动创建 GitLab repo）
- **权限控制**：
 - 公开课题：所有用户可访问
 - 专有课题：仅指定成员可访问
- **成员管理**：支持为课题添加成员并分配不同角色

### 3.4 作业管理
- **作业创建**：管理员和教师可在课题中创建作业
- **作业提交**：参与者在个人分支中提交作业（分支命名：作业标题+用户名）
- **作业查看**：教师可查看所有参与者提交的作业列表，学生可查看自己的作业以及老师的评语
- **作业评分**：教师可对作业进行评分，学生可查看自己的评分

### 3.5 文档管理
- **自动索引**：自动识别课题 repo 中的文档文件（doc, excel, ppt, pdf 等）
- 支持文档单独新建（不关联到课题）
- **集中管理**：使用 MinIO 进行文档存储和管理
- **文档属性**：
 - 标题默认为文件名
 - 简介默认为文件名
 - 支持分类管理
- **编辑权限**：
 - 管理员/教师：直接修改文档属性
 - 研究员/学生：修改需经审核

### 3.6 话题讨论
- 基于 GitLab Issues 实现课题讨论功能，话题必须依托于课题
- 支持话题分类、标签
- 支持评论、点赞等互动功能
- 权限继承自 GitLab 项目权限

### 3.7 通知系统
- 基于 GitLab 通知机制
- 在关键操作（新增、编辑、删除）时自动通知相关参与者
- 支持系统级和课题级通知

### 3.8 第三方系统集成
- **账号同步功能**：提供完整的 RESTful API 用于第三方系统用户同步
- **双密钥认证机制**：
 - `SYNC_API_KEY`：内部系统使用，支持高级权限操作
 - `THIRD_PARTY_API_KEY`：外部系统使用，权限受限
- **批量操作支持**：支持批量用户创建和更新
- **外部系统标识**：支持记录外部系统ID和来源信息

## 4. 第三方同步API

### 4.1 API认证机制
- **双密钥设计**：
 - `THIRD_PARTY_API_KEY`：外部系统使用，权限受限
- **请求头认证**：`X-API-Key: your_api_key_here`

### 4.2 核心API功能
- **用户创建**：支持单个用户创建并返回JWT token
- **用户更新**：支持用户信息更新和角色设置
- **用户查询**：支持按ID或用户名查询用户信息

### 4.3 数据字段支持
- 基础信息：用户名、密码、邮箱、姓名
- 角色设置：支持所有教育角色类型
- 扩展信息：院系、学号、工号、联系方式
- 外部标识：外部系统ID和来源信息
