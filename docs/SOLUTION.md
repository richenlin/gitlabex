# GitLabEx 教育协作平台 - 解决方案设计

## 概述

GitLabEx 是一个基于 GitLab 的教育协作平台，专为教学场景设计的现代化教育管理系统。通过深度集成 GitLab 生态系统，提供完整的教育场景解决方案。

### 核心理念

- 🔗 **最大化复用GitLab能力** - 用户管理、团队协作、权限控制、项目管理完全依赖GitLab
- 📚 **教育场景优化** - 针对教学流程的专业功能设计
- 🎯 **简化操作流程** - 为教师和学生提供直观易用的界面
- 🚀 **企业级安全** - 完整的OAuth认证和API安全机制
- 🌐 **第三方集成** - 完善的第三方系统集成能力

## 权限系统设计

### 角色定义

```go
// 教育角色枚举 - 基于GitLab权限映射
type EducationRole int

const (
    EduRoleGuest     EducationRole = 10 // GitLab Guest -> 访客
    EduRoleStudent   EducationRole = 20 // GitLab Reporter -> 学生
    EduRoleAssistant EducationRole = 30 // GitLab Developer -> 研究员
    EduRoleTeacher   EducationRole = 40 // GitLab Maintainer -> 教师
    EduRoleAdmin     EducationRole = 50 // GitLab Owner -> 管理员
)
```

### 权限控制规则

#### 1. 系统级权限
- **管理员（Admin）**: 系统管理员，拥有所有权限，可以管理用户组和权限分配
- **教师（Teacher）**: 可以创建和管理课题、作业，查看所有学生提交
- **助教（Assistant）**: 可以管理课题、作业，查看参与课题学生提交
- **学生（Student）**: 可以参与课题，提交作业，查看个人统计
- **访客（Guest）**: 只读权限，只能看到首页

#### 2. GitLab权限映射
- **GitLab Owner**: 自动映射为系统管理员
- **GitLab Maintainer**: 自动映射为教师角色
- **GitLab Developer**: 自动映射为助教角色（可选）
- **GitLab Reporter**: 自动映射为学生角色

#### 3. 课题级权限
- **课题创建者**: 完全管理权限，包括添加学生、管理作业、评审提交
- **课题参与学生**: 参与课题开发、提交作业、在个人分支进行开发

#### 4. 资源级权限
- **文档权限**: 基于GitLab Wiki权限
- **代码权限**: 基于GitLab Project权限
- **讨论权限**: 基于GitLab Issues权限
- **作业权限**: 教师管理所有作业，学生只能访问自己的作业


## 系统功能设计

- 项目由 社区首页、研究课题、话题、文档四个栏目构成
- 项目依托于gitlab做二次开发。研究课题就是repo项目，可以在线协作开发提交代码文件；话题就是研究课题的issuse，话题围绕研究课题进行讨论，可以对某一话题进行评论点赞；课题文件中如果包含pdf、doc、ppt等文档类型文件，则索引到文档进行集中管理（可以进行简介、分类）
- 研究课题repo中包含的场景和算法源码，支持有权限的用户在线预览和编辑（类似github）
- 项目用户分为四种角色 管理员（Owner）、老师（Maintainer）、研究员（Developer）、学生(Reporter)。管理员拥有所有研究课题、话题等最高权限。老师可以新建、编辑、删除研究课题，以及管理维护自己归属的研究课题相关的内容（话题、讨论、文档）；研究员可以修改项目内容、文件等；学生可以参与课题开发、话题讨论、文档维护等
- 研究课题分为公开课题、专有课题。管理员和老师可以新增和删除公开课题，其他用户均有权限参与编辑维护。管理员和老师可以新增和删除专有课题，管理员和老师可以指定成员参与专有课题，课题成员才能参与编辑维护
- 管理员和老师可以在研究课题中创建作业（作业包括标题、内容描述）；研究课题参与者可以提交自己的作业（每个参与者在研究课题repo中有一个自己的代码分支，分支内容就是作业）；管理员和老师可以看到所有参与者提交的作业列表（研究课题repo分支罗列，默认以作业标题+参与者作为作业列表标题）
- 文档管理功能，是自动识别 repo（研究课题和作业）中的文档（doc、excel、ppt、pdf等文档类型）文件，进行集中管理维护。文档标题默认为文件名，文档简介默认为文件名。管理员及老师可以修改文档标题、文件简介、文档分类。学生也可以修改文档标题、文件简介、文档分类，但是需要经过审核才能生效。
- 基于GitLab通知机制实现通知管理功能，在新增、编辑、删除等操作时触发，通知内容参与者
